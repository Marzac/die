Detailed Description

Per-surface lighting terms, from the SURFACE_FLAGS The pixel is lit as: lit = texel * (env + glowmap) + (bleedEnv + glowmap)^2 * bleed The square only burns the brightly lit spots; bleedEnv is the env light with FLAG_SUN_BLEED, black otherwise.
