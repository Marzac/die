void Rigger::renderAnimationFrame ( QImage & image,
int animationId,
float frameCursor )

Render an interpolated pose of an animation, fitted to its bounding box, into an image (e.g. for sprite sheet baking).

Parameters
imagedestination, cleared to transparent and entirely filled by the animation's (padded) bounding box
animationIdindex into rig.animations
frameCursorframe position; interpolates between the floor and ceiling neighbour frames, wrapping across the animation's loop

◆ renderFlesh()

void Rigger::renderFlesh ( QImage & image,
const QVector2D & org,
float zoom,
const QList< Joint > & joints )

Render the bone flesh of a single pose into an image.

The image is cleared to transparent first. org / zoom map world units to image pixels, the same way the live editor view does; joints is the pose to render (indexed the same way as the bones' jointID1/2).
