Detailed Description

Texture strip operations.

texture strip helpers

A strip stacks square power-of-two tiles, rotated a quarter-turn, in 32-bit (A)RGB. Mipmaps chain its levels in one buffer: level 0, then halved down to 1x1. Key color texels are holes in every level.
